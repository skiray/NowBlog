## 3. 合规必备

### 3.1 隐私政策（H5 页面，必须上线前发布）

必须包含：收集哪些信息（手机号、昵称、头像、记账数据、设备信息）、用途、保存期限、用户权利（查询/导出/注销删除）、联系方式。**注销流程必须真实可用**（应用商店审核强校验项）。

### 3.2 权限最小化声明

| 权限 | 用途 | 可否关闭 |
|---|---|---|
| 网络 | 数据同步 | 必须 |
| 存储（相册） | 设置头像 | 可选 |
| 通知 | 预算提醒 | 可选 |

不申请：位置、通讯录、短信读取、电话。**记账 App 申请敏感权限是审核被拒高发区。**

### 3.3 其他

- [ ] 用户协议（模板 + 法律顾问过一遍，预算允许时）
- [ ] ICP 备案号放置于设置页/隐私政策页
- [ ] 崩溃时用户数据不丢失声明（同步失败本地保留的产品承诺）

## 4. 服务端上线（W15-W16）

- [ ] prod 环境搭建（与 staging 同构 docker compose；Nginx + HTTPS + 域名）
- [ ] **数据库每日自动备份**已启用并**完成一次真实恢复演练**（恢复到临时实例核对数据）
- [ ] 监控告警就位：Sentry（客户端）、云监控（CPU/内存/磁盘/DB 连接）、错误日志告警（同步失败率 > 1% 告警）
- [ ] 限流配置生效（见 05-api-design.md 第 12 节）
- [ ] 万能验证码仅存在于审核备注环境，**prod 禁用**

- [ ] 回滚预案：镜像版本保留最近 5 个；回滚 = 切镜像 + 数据库向前兼容（迁移只加不删）

## 5. 灰度发布（W17）

| 步骤 | 内容 | 观察指标 | 通过线 |
|---|---|---|---|
| 1 | TestFlight + 安卓各市场「开放测试」100 人（亲友+种子） | 崩溃率、同步失败率 | 崩溃 < 1%、同步失败 < 0.5%，观察 3 天 |
| 2 | 扩到 500 人（灰度用户群） | 以上 + 记一笔耗时埋点 | P95 ≤ 5s；观察 3 天 |
| 3 | 各市场正式提交/全量 | 留存与周活 | 周复盘机制启动 |

**回滚触发条件**：崩溃率 ≥ 1.5% 或出现资损类缺陷（金额错误）→ 立即下架该版本/回滚服务端。
